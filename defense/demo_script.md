# 现场演示脚本（约3分钟）

1. 首页（20秒）：指出数据规模、默认模型和统一测试集结果。
2. 电影详情（35秒）：搜索一部电影，切换用户，展示预测评分；加入“想看”。
3. 个性化推荐（50秒）：生成Top-5，强调已评分电影被排除，每部至少两条规则化理由；给一部电影“不喜欢”反馈后刷新。
4. 我的观影（30秒）：把想看改为已看并录入个人评分，展示SQLite即时更新。
5. 模型实验室（35秒）：展示五模型RMSE/MAE/R²、效率和重要性，明确MLP精度最佳、XGBoost推理更快。
6. 收尾（10秒）：说明在线反馈为临时演示数据，云端重启可能清空。

故障预案：若公网应用刚休眠，等待官方数据下载与模型初始化；若网络异常，展示本地已验收版本和 `reports/stage7/clean_deployment_result.json`，不得把本地地址说成云端地址。
