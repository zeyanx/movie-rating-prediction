# 现场演示运行手册

## 标准流程（5分钟）

1. 打开公开首页，指出100000/943/1682和系统健康。
2. 选择匿名用户1，说明编号不是身份认证。
3. 进入电影详情，搜索并选择 `Toy Story`。
4. 展示训练期统计、分布图和1～5范围内的MLP预测。
5. 勾选多模型比较，说明RF/XGBoost按需加载。
6. 进入推荐页，生成10条推荐并确认无重复。
7. 解释一条推荐的预测、类型匹配和热度理由。
8. 保存一条“想看”记录。
9. 在“我的观影→网页记录”立即读回并演示可编辑/导出。
10. 打开模型实验室，展示MLP RMSE 0.9290及RF排名。
11. 切换效率、Bootstrap、重要性和分段标签。
12. 结束时说明随机划分、未验证NDCG和SQLite临时性。

## 故障预案

- **网络正常：** 使用公开URL，首次冷启动预留1～2分钟。
- **冷启动：** 保持页面等待，说明官方数据下载、MD5和模型缓存过程，不重复刷新。
- **云端不可用：** `conda activate movie` 后运行 `streamlit run app.py`，明确这是本地备用。
- **页面失败：** 展示 `reports/stage7/screenshots/` 六张真实云端截图和验证报告。
- **3分钟压缩版：** 首页30秒、详情40秒、推荐60秒、我的观影30秒、模型实验室30秒、限制10秒。

## 演示前检查

- 打开GitHub与在线应用；确认首页健康文字。
- 准备用户1和Toy Story；不要展示账户后台或任何凭据。
- 确认网络、电源和本地备用服务。
- 提醒评委云端测试反馈可能在重建后重置。
