# 答辩常见问题与回答（22组）

1. **为什么选MovieLens 100K？** 数据公开、字段清晰、规模能在CPU上完整复现，适合统一比较；但年代早，外推受限。
2. **为什么使用随机划分？** 课程目标是控制变量比较模型，分层随机划分能保持评分分布；它不模拟未来预测。
3. **为什么不使用时间划分？** 本阶段先保证与全部模型已有协议一致。时间划分是下一步更贴近线上场景的验证。
4. **如何避免数据泄漏？** 先划分，再只用训练集计算用户/电影统计和预处理参数，网页推荐不读取测试评分。
5. **为什么做五折交叉验证？** 降低单一验证划分的偶然性，用于训练集内模型选择，不替代最终测试集。
6. **为什么测试集不能调参？** 反复按测试结果选择参数会把测试信息泄漏到模型选择，指标将过于乐观。
7. **为什么MLP优于随机森林？** 本实验中用户与电影嵌入捕捉了高基数ID交互，且置换重要性最大；不是普遍规律。
8. **为什么随机森林仍是最佳集成模型？** 其RMSE、MAE、R²均优于另两种集成模型，并保持可解释性和可接受推理速度。
9. **为什么没有实现NCF？** NCF被定义为可选内容；为控制范围和保证完整闭环，本研究只报告实际实现的MLP。
10. **Embedding如何工作？** 它为每个离散ID学习一个低维向量，相似交互模式可以在潜在空间形成相近表示。
11. **XGBoost与随机森林有什么区别？** 随机森林并行训练随机树并平均，主要降方差；XGBoost按残差顺序提升并加正则。
12. **AdaBoost为何较差？** 在本特征和参数下对误差样本的顺序加权产生更强均值偏差；结论仅限当前实验。
13. **RMSE与MAE有何区别？** RMSE平方后平均，对大误差敏感；MAE单位直观且对异常误差更稳健。
14. **R²为什么不高？** 用户偏好具有随机性，数据稀疏且特征有限；0.3189仍明显优于均值基线但不能解释全部方差。
15. **Bootstrap说明什么？** 对同一测试样本配对重采样，估计模型误差差值区间；不证明跨平台或未来数据必然有效。
16. **特征重要性代表因果吗？** 不代表。它仅描述模型和当前样本下的预测依赖；树重要性和置换重要性定义也不同。
17. **如何处理冷启动？** 未知ID映射到保留索引，统计缺失时使用全局回退；但完全新用户个性化仍有限。
18. **推荐理由如何生成？** 根据MLP预测、训练期类型偏好、评分数量和贝叶斯平滑口碑生成可追溯规则文本。
19. **为何没有NDCG或Recall@K？** 本项目的主要实验目标是显式评分预测，未构造排序相关性协议，因此不声称验证Top-N质量。
20. **SQLite为什么不适合生产？** Community Cloud本地磁盘不保证跨休眠、重启、构建持久，且当前没有用户认证与并发治理。
21. **Streamlit Cloud如何加载模型？** MLP默认用`st.cache_resource`一次加载；RF和XGBoost在用户请求多模型比较时延迟加载。

22. **为什么扩展中国电影库中的部分影片不能预测？** 既有模型只学习了MovieLens 100K中的用户—电影交互。扩展影片没有对应`movie_id`和训练评分，直接给分会造成伪精确，因此系统将其标记为冷启动，只支持资料检索和个人记录；中文片名映射则不会改变已有影片的预测。
23. **下一步如何改进？** 时间切分、嵌套评估、Recall/NDCG、多样性、公平性、NCF或序列模型，以及外部持久数据库。
