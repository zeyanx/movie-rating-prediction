# 基于集成学习与神经网络的电影评分预测对比研究（论文初稿）

## 摘要

本文面向电影评分预测与个性化推荐场景，基于 MovieLens 100K 数据集构建从数据治理、特征工程、模型训练、统一测试到网页部署的完整实验系统。研究对象包含全局均值基线、随机森林、AdaBoost、XGBoost 与基于 PyTorch 的多层感知机（MLP）。数据集含 100000 条 1～5 分显式评分、943 名用户和 1682 部电影；实验采用固定随机种子 42、按评分分层的 80%/20% 训练测试划分，所有模型共享同一 20000 条测试集。为防止信息泄漏，用户与电影历史统计量仅由训练集计算，测试集仅在最终评估阶段使用。

实验表明，MLP 在固定测试集上取得最佳结果：RMSE 为 0.9290、MAE 为 0.7333、R² 为 0.3189；随机森林次之，三项指标分别为 0.9570、0.7592 和 0.2772。相较全局均值基线，MLP 的 RMSE 和 MAE 分别改善 17.47% 和 22.37%。2000 次配对 bootstrap 显示，MLP 相对随机森林的 RMSE 差值 95% 置信区间为 [-0.0326,-0.0233]，区间不跨 0。特征分析显示，随机森林最依赖训练集统计特征；MLP 的用户嵌入与电影嵌入贡献最突出。工程上，MLP 模型体积约 0.55 MB，但 CPU 推理吞吐低于 XGBoost；因此系统默认使用 MLP 保证精度，同时保留全局均值作为回退模型。

本文进一步实现了 Streamlit 多页面系统，支持电影搜索、评分预测、个性化推荐、中文推荐理由、观影记录与模型实验展示。为遵守 MovieLens 许可，公开部署不重新分发原始数据，首次启动时从 GroupLens 官方地址下载并校验 MD5，再生成固定划分；本地用户反馈存入临时 SQLite，云端重启后可能丢失。研究结果证明，在本数据和实验条件下，神经网络能够学习用户—电影交互的非线性表示并优于三种集成模型，但其结论仍受数据年代、稀疏性、随机划分和单次实验规模限制。

在应用增强层，系统为1,324部MovieLens影片建立中文片名与别名索引，并将300部带真实评分的中国电影纳入统一电影库。两类影片共用动作、冒险、喜剧、剧情等中文题材筛选，并按影片来源调用各自评分模型；中文字段只改变检索与显示，不改变原始训练主键和实验指标。系统同时保留48部中国电影基础资料目录用于观影记录；对于没有训练评分的条目明确标记为冷启动对象，不输出缺乏依据的预测分。

**关键词：** 电影评分预测；集成学习；随机森林；XGBoost；多层感知机；个性化推荐；Streamlit

## Comparative Study of Movie Rating Prediction Based on Ensemble Learning and Neural Networks

### Abstract

This project establishes a reproducible movie-rating prediction pipeline on MovieLens 100K and compares a global-mean baseline, Random Forest, AdaBoost, XGBoost, and a PyTorch embedding-based multilayer perceptron under the same stratified 80/20 split. All historical aggregate features are fitted using the 80,000 training interactions only, while the 20,000 held-out interactions are reserved for final evaluation. The MLP achieves the best test performance with an RMSE of 0.9290, an MAE of 0.7333, and an R² of 0.3189. Paired bootstrap analysis with 2,000 resamples further supports its advantage over the three ensemble models on this test set. A five-page Streamlit application provides movie search, rating prediction, reasoned Top-N recommendations, viewing records, feedback, and an experiment dashboard. To respect the MovieLens license, the public repository does not redistribute rating data; the cloud application downloads and verifies the official archive at first startup. The results apply only to the dataset, split, and models evaluated here and should not be interpreted as online ranking or click-through improvements.

**Keywords:** movie rating prediction; ensemble learning; Random Forest; XGBoost; multilayer perceptron; recommender system; Streamlit

## 相关技术与理论补充

随机森林通过样本和特征双重随机性降低树模型方差；AdaBoost.R2 通过调整样本权重组合弱回归器；XGBoost 在加法树目标中加入模型复杂度正则项。PyTorch MLP 使用 Embedding 将高基数离散 ID 映射到连续潜在空间，再与显式属性拼接。五折交叉验证仅在训练集内执行：训练数据分为五份，每轮使用四份拟合、一份验证，最终汇总五轮 RMSE；固定测试集不参与超参数选择。

全局均值预测为：

$$\hat r_{ui}=\mu_{train}=\frac{1}{|\mathcal D_{train}|}\sum_{(u,i)\in\mathcal D_{train}}r_{ui}$$

贝叶斯平滑电影口碑采用：

$$B_i=\frac{n_i\bar r_i+m\mu}{n_i+m}$$

其中 $n_i$ 为电影训练期评分数，$\bar r_i$ 为电影均分，$\mu$ 为训练集总体均值，$m$ 为先验强度。网页最终推荐分为：

$$S_{ui}=0.85\hat r^{MLP}_{ui}+0.10G_{ui}+0.05B_i$$

其中 $G_{ui}$ 是用户类型偏好得分。MLP 原始输出经约束映射到评分范围：

$$\hat r^{MLP}_{ui}=1+4\,\sigma(z_{ui})$$

该输出约束避免预测超出 1～5，但不会自动解决极端评分向均值收缩的问题。

## 1 绪论

### 1.1 研究背景与意义

互联网内容平台面临典型的信息过载问题。评分预测以用户、物品及上下文信息为输入，估计用户对未观看电影的偏好，是排序、召回后重排与解释推荐的重要基础。传统集成学习对表格特征适配良好，训练过程稳定并可通过特征重要性解释；神经网络则可以将高基数用户和电影编号映射为稠密向量，从交互中自动学习潜在表示。二者在相同数据划分和评价协议下的差异，具有课程研究和工程选型价值。

本课题的意义有三点：第一，建立可复现的统一对比框架，避免因不同测试集造成不可比结论；第二，同时讨论预测精度、统计稳定性、推理效率和可解释性；第三，将离线实验转化为可操作网页，使模型不止停留在训练脚本。

### 1.2 研究内容

本文完成六项工作：（1）将官方 `u.data`、`u.item`、`u.user` 转换为规范 CSV，并建立规模、外键和哈希验证；（2）实现全局均值基线；（3）构造用户属性、电影类型、时间和训练集统计特征，训练随机森林、AdaBoost、XGBoost；（4）以 PyTorch 构建含用户/电影嵌入的 MLP；（5）在统一测试集上比较 RMSE、MAE、R²，并进行配对 bootstrap、分段误差和重要性分析；（6）开发并准备部署 Streamlit 系统。

### 1.3 论文结构

第2章说明数据与评价设计；第3章描述模型和特征；第4章给出实验结果；第5章介绍网页系统；第6章总结局限与改进方向。

## 2 数据与实验设计

### 2.1 数据集

MovieLens 100K 是 GroupLens 发布的稳定基准。经脚本验证，本项目版本包含 100000 条评分、943 名用户、1682 部电影，评分范围为 1～5。用户字段包括年龄、性别、职业与邮编；电影字段包括标题、上映日期、IMDb 链接及 19 个原始类型标记。评分矩阵稀疏，且用户至少有一定评分历史，适合作为小规模显式反馈研究基准。

### 2.2 预处理与划分

先依据官方分隔符和 `latin-1` 编码读取源文件，再以 UTF-8 CSV 保存。评分数据按 `rating` 分层，以 `test_size=0.2`、`random_state=42` 划分为 80000 条训练样本和 20000 条测试样本。固定清单记录源数据、训练集和测试集 SHA-256，分别为 `61dd...f279`、`d2c8...9053` 和 `ea419...c91`。分层使五个评分等级的比例在训练和测试集合中基本一致。

为避免泄漏，用户平均分、电影平均分、评分次数等统计量只从训练集构造；网页推理也不读取固定测试集。对于训练期未出现的 30 部测试电影，使用全局统计或未知编号机制处理。

### 2.3 评价指标

设真实评分为 $y_i$，预测为 $\hat y_i$，样本数为 $n$：

$$RMSE=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat y_i)^2}$$

$$MAE=\frac{1}{n}\sum_{i=1}^{n}|y_i-\hat y_i|$$

$$R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}$$

RMSE 对大误差惩罚更强，MAE 更直观且稳健，R² 表示相对均值基线所解释的方差比例。主排序依据 RMSE，同时复核 MAE 与 R²。模型差异通过对同一测试样本重采样 2000 次的配对 bootstrap 估计 95% 置信区间。

## 3 方法

### 3.1 全局均值基线

基线输出训练集全部评分均值 3.5298625。该模型不利用个体信息，但提供最低复杂度参照和部署失败时的安全回退。测试 RMSE 为 1.1257，MAE 为 0.9447，R² 约为 0。

### 3.2 特征工程

表格模型使用四组信息：用户属性（年龄、性别、职业等）、电影类型、时间特征以及仅由训练集计算的统计特征。时间字段进一步表达年份、月份、星期及周期编码；电影类型保留官方 19 类多标签。类别字段通过一致的预处理器编码，缺失或未知类别采用稳定回退，保证网页输入与训练模式一致。

### 3.3 集成学习模型

随机森林通过 bootstrap 样本训练多棵回归树，并随机选择候选特征，以平均降低方差。AdaBoost 回归器顺序关注高误差样本，将多个弱回归器加权组合。XGBoost 以加法树模型优化带正则项的目标，使用梯度提升和高效树构建机制。三种方法均在训练集内执行 5 折交叉验证，最终模型再在完整训练集拟合；超参数和随机种子由配置文件固化。

### 3.4 MLP 神经网络

MLP 将用户 ID、电影 ID、职业和性别映射为可训练嵌入，并与标准化连续变量、电影类型多热向量拼接。拼接向量经过全连接层、非线性激活和正则化后输出评分。优化目标为均方误差，训练阶段使用验证集选择最佳轮次，最终按已确定配置训练部署模型。输出裁剪到 [1,5]，以符合评分语义。

### 3.5 推荐得分与解释

网页候选集排除训练期已评分电影及用户在本地标记不喜欢的电影。最终分数由 MLP 预测、类型偏好和贝叶斯平滑流行度按 0.85、0.10、0.05 加权，并保持 1～5 范围。推荐理由至少包含两条，例如“预测评分较高”“符合历史偏好类型”“评分人数较多且口碑稳定”。这些理由来自可核验规则，不等同于因果解释。

## 4 实验结果与分析

### 4.1 总体结果

|模型|RMSE|MAE|R²|相对基线RMSE改善|
|---|---:|---:|---:|---:|
|MLP|0.9290|0.7333|0.3189|17.47%|
|随机森林|0.9570|0.7592|0.2772|14.98%|
|XGBoost|0.9703|0.7707|0.2569|13.80%|
|AdaBoost|1.0630|0.8712|0.1083|5.57%|
|全局均值|1.1257|0.9447|≈0|0|

五项模型的三项指标排序一致，MLP 总体最优。MLP 相对随机森林的 RMSE 降低 0.0280，MAE 降低 0.0259；其 95% bootstrap 区间分别为 [-0.0326,-0.0233] 与 [-0.0299,-0.0218]，均不跨 0。相对 XGBoost 和 AdaBoost 的区间也不跨 0。不过统计显著并不代表所有应用场景都有同等业务收益，仍需考虑推理成本和数据漂移。

### 4.2 误差特征

MLP 平均误差为 0.0146，预测略偏高；随机森林平均误差为 -0.0155，略偏低；AdaBoost 平均误差 -0.3183，存在明显低估。MLP 的绝对误差中位数为 0.6008，90% 分位数为 1.4740，且误差不超过 0.5 的比例为 40.84%。按真实评分分段可见，所有模型在极端评分 1 和 5 上误差更大，说明向总体均值收缩是共同难点。

### 4.3 可解释性

随机森林的重要性中，训练集统计特征占 78.60%，时间、用户属性和电影类型分别占 9.66%、7.27% 和 4.46%。XGBoost 更依赖用户属性与电影类型。MLP 置换分析中，电影嵌入和用户嵌入分别占正向归一化重要性的 41.75% 和 41.74%，类型为 7.72%，说明离散身份表示是其主要预测来源。置换重要性反映在既定验证样本上的性能变化，不能解释单个推荐的因果机制。

### 4.4 工程效率

XGBoost 的 CPU 推理约为每 1000 行 13.41 ms，随机森林约 21.37 ms，MLP 约 82.97 ms。随机森林产物约 38.00 MB，MLP 与 XGBoost 均约 0.55 MB。因本项目规模较小，MLP 的绝对响应时间仍可接受；网页通过 `st.cache_resource` 缓存模型、`st.cache_data` 缓存静态数据，避免重复加载。

## 5 系统设计与实现

系统采用单一 `app.py` 入口和五个页面：首页展示项目与模型结果；电影详情支持搜索、评分预测和本地状态记录；个性化推荐输出分数及至少两条中文理由；我的观影管理想看、已看、评分和反馈；模型实验室展示指标、效率、误差和重要性。服务层分离配置、数据、模型、推荐和 SQLite 操作，便于测试。

部署包不包含 MovieLens 原始 CSV。首次运行时，应用仅从 GroupLens 官方 URL 下载 ZIP 和 MD5，校验固定 MD5 `0e33842e24a9c977be4e0107933c0723`，进行防路径穿越解压，转换 CSV，再按固定规则重建训练集。模型由资源缓存加载，数据由数据缓存读取。SQLite 位于临时文件系统，仅作为无需登录的课程演示；云端休眠、重启或重新部署均可能清空反馈。

## 6 结论与展望

本文在严格一致的测试条件下完成了集成学习与 MLP 的比较。MLP 以 RMSE 0.9290 获得最佳精度，且 bootstrap 结果支持其相对三种集成模型的稳定优势；随机森林仍在准确率、易解释性与推理效率之间表现均衡。工程系统把预测、推荐、解释和反馈整合为可运行网页，并通过运行时官方数据获取解决公开部署与数据许可之间的矛盾。

本研究的主要局限包括：数据形成于 1990 年代，不能代表当前内容分布；随机划分未模拟时间顺序推荐；评分预测不等同于 Top-N 排序质量；人口属性存在公平性风险；单机 CPU 基准不能外推到所有环境；测试集已用于最终模型选择，后续工作不能继续用它调参。未来可采用时间切分和嵌套评估，引入 NCF、矩阵分解或序列模型，增加 Recall@K、NDCG@K、多样性和新颖性评价，并使用持久化数据库与身份认证完善线上反馈闭环。
