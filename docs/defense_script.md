# 6～8分钟答辩讲稿

**第1页。** 各位老师好，我的课题是《基于集成学习与神经网络的电影评分预测对比研究》。我关注两个问题：第一，在统一数据和评价协议下，表格型集成模型与嵌入式神经网络谁的评分预测效果更好；第二，如何把实验结果实现成可搜索、可预测、可推荐和可反馈的网页系统。

**第2页。** 数据采用 MovieLens 100K，共100000条1到5分评分、943名匿名用户和1682部电影。它规模适合本科项目完整复现，同时包含用户属性、电影类型和时间信息。需要强调，公开可下载不等于允许重新分发，因此公开仓库没有放原始评分文件。

**第3页。** 技术路线从官方下载和MD5校验开始，依次进行CSV转换、固定划分、基线、集成学习、MLP、统一对比，再封装成Streamlit系统。每阶段都有独立脚本、配置和验证器，最终部署仍复用训练时的数据定义。

**第4页。** 我用按评分分层的80/20随机划分，随机种子42，得到80000条训练数据和20000条测试数据。用户均分、电影均分和计数等统计只从训练集计算，避免提前看到测试答案。特征分为用户属性、电影类型、时间和训练集统计四组。

**第5页。** 集成模型包括随机森林、AdaBoost和XGBoost。随机森林通过多棵随机树平均降低方差；AdaBoost逐轮提高高误差样本权重；XGBoost通过梯度提升和正则化学习加法树。三种模型都只在训练集内部完成五折交叉验证。

**第6页。** MLP的核心是用户嵌入与电影嵌入。它们把高基数ID变为可学习的稠密向量，再与职业、性别、年龄、类型和时间特征拼接。输出使用1加4乘sigmoid限制到1至5。置换实验显示用户和电影嵌入贡献最大，这能解释它在本实验中优于只依赖显式表格特征的模型，但不能推广成普遍结论。

**第7页。** 评价指标包括RMSE、MAE和R²。RMSE更强调大误差，MAE表示平均绝对偏差，R²表示相对均值模型解释的方差。最终比较只能看同一固定测试集，测试集不能继续拿来调参。

**第8页。** MLP的RMSE为0.9290、MAE为0.7333、R²为0.3189，三项指标均为第一。随机森林是最佳集成模型，RMSE为0.9570；XGBoost为0.9703；AdaBoost为1.0630；全局均值为1.1257。MLP相对基线的RMSE改善17.47%。

**第9页。** 2000次配对bootstrap中，MLP相对随机森林的RMSE差值95%区间为负且不跨0，因此在这组测试样本上优势稳定。分段分析表明1分和5分等极端评分更难预测。树模型原生重要性与MLP置换重要性定义不同，不能直接把数值大小当作因果贡献。

**第10页。** 系统有首页、电影详情、个性化推荐、我的观影和模型实验室五页。推荐得分由MLP预测、类型偏好和贝叶斯热度组成。理由来自可核验规则，例如预测较高、类型匹配、训练评分充分，每部至少两条，但不是因果解释。

**第11页。** 云端部署从GroupLens官方地址首次下载数据、校验MD5并复现固定哈希。随机森林使用Git LFS。部署中发现Windows和Linux换行符导致同内容文件哈希不同，因此将CSV行结束符显式固定，修复后云端五页通过。SQLite仅用于课程演示，重启、休眠和重新部署后可能丢失。

**第12页。** 结论是MLP在本数据和协议下精度最好，随机森林在集成模型中最优且解释更直观。局限包括数据年代早、随机划分不模拟未来、评分误差不等同于Top-N排序收益、没有进行NDCG或线上点击实验。后续可采用时间切分、嵌套验证、NCF与持久化数据库。我的汇报完毕，谢谢老师。
